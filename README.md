# CanteraPFR

> **Note**: CanteraPFR has been fully merged into [majordome](https://github.com/wallytutor/python-majordome).

All functionality has been migrated and modernized:
- **Plug-Flow Reactor Solver & C++ IDAS Core**: `majordome.plug_flow` (`CPFR`, `PyPFR`).
- **Kinetic Mechanism Reduction & DRG**: `majordome.engineering.reduction` (`SimplifyDRG`, `SimplifyDRGManager`, `BaseGraph`, `DirectedGraph`, `extract_submechanism`).
- **Dimensionless Transport Numbers**: `majordome.engineering.transport` (`SolutionDimless`).
- **Documentation**: Integrated into Majordome's Quarto documentation book.
